## ✦ ایداکد چیست؟

**ایداکد** یک پلتفرم ایرانی برای وصل کردن **صاحبان ایده و کسب‌وکار** به **برنامه‌نویس‌ها** است.
ایده یا مشکلت را می‌نویسی، برنامه‌نویس‌ها آن را می‌بینند، جواب می‌دهند و با هم آن را به یک محصول واقعی تبدیل می‌کنید.

</div>

<p align="center"><img src="https://raw.githubusercontent.com/IdaCode-ir/.github/main/profile/assets/how-it-works.svg" width="100%" alt="مراحل کار در ایداکد"></p>

<div dir="rtl">

| 💡 برای صاحبان ایده | 👨‍💻 برای برنامه‌نویس‌ها |
| :---: | :---: |
| ایده یا مشکلت را ثبت کن؛ نیازی به دانش فنی نیست. | پروژه‌های واقعی را ببین و روی ایده‌هایی که دوست داری کار کن. |
| برنامه‌نویس مناسب را پیدا کن و ایده‌ات را به محصول تبدیل کن. | با صاحب ایده همکاری کن و محصول بساز. |

</div>
